## Introduction

Une **socket** permet à deux programmes de communiquer à travers un réseau.  
Nous allons créer un mini-jeu où un **joueur client** affronte un **serveur arbitre**.  

Le protocole utilisé sera **TCP**, qui garantit la fiabilité des échanges.



---

## Rappel du fonctionnement

**Serveur :**

- Attendre une connexion.
- Recevoir le coup du joueur.
- Déterminer le résultat et répondre.

**Client :**

- Se connecter au serveur.
- Envoyer son choix.
- Recevoir le résultat.

---

## 1. Premier test : communication simple

### **Serveur**

```python
import socket

server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server.bind(('0.0.0.0', 12345))
server.listen(1)
print("Serveur en attente...")

conn, addr = server.accept()
print(f"Connecté par {addr}")

data = conn.recv(1024).decode()
print(f"Message reçu : {data}")

# À compléter : renvoyer un message au client
conn.sendall("_________________________".encode())

conn.close()
server.close()
```

## 2. Créer le jeu Pierre-Feuille-Ciseaux

### Fonction pour déterminer le gagnant

```python
def resultat(j1, j2):
    if j1 == j2:
        return "Égalité"
    elif (j1 == "pierre" and j2 == "ciseaux") or \
         (j1 == "ciseaux" and j2 == "papier") or \
         (j1 == "papier" and j2 == "pierre"):
        return "Joueur 1 gagne"
    else:
        return "Joueur 2 gagne"
```
